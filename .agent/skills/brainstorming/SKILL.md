# Brainstorming Ideas Into Designs

## Establish Shared Understanding
1. **Discover Intent:** Identify intended outcome, user persona, and success criteria.
2. **Reflect Understanding:** Summarize scope, constraints, and assumptions in a concise review format.
3. **Select Path:**
   - **Spike:** Feasibility question. Produce an answer/probe, not retained production code.
   - **Bounded:** Well-scoped modification to existing code. Present a short in-chat design and wait for user sign-off before coding.
   - **Architectural:** New subsystem, project, or interface change. Create full design specification, review, then invoke `writing-plans`.
