# Using Superpowers

## Core Rule
Invoke relevant process skills before writing code, proposing fixes, or creating plans:
- **New Feature / Creative Work:** Invoke `brainstorming` first.
- **Bug / Test Failure:** Invoke `systematic-debugging` first.
- **Multi-step Implementation:** Invoke `writing-plans` first.
- **Before Claiming Completion:** Invoke `verification-before-completion` first.

## Priority Order
When multiple skills apply:
1. Process skills come first (`brainstorming`, `systematic-debugging`).
2. Planning skills second (`writing-plans`).
3. Implementation / execution skills third (`test-driven-development`).
4. Verification skills last (`verification-before-completion`).
