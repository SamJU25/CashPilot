# Test-Driven Development (TDD)

## The Cycle
1. **Red:** Write a minimal automated test exercising the expected behavior. Run it and verify it fails with the expected error.
2. **Green:** Write the absolute minimal implementation code to pass the test. Run the test and verify it passes.
3. **Refactor:** Clean up code, remove duplication (DRY), and optimize while keeping tests green.
4. **Repeat:** Advance one small unit test at a time.
