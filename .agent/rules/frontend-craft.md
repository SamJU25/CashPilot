# 4-Pillar Frontend Design & Motion Protocol

Scope: Antigravity coding assistant only. Do not add to JARVIS runtime settings.

## 1. Situational Execution Flow
- **When creating UI:** Enforce intentional typography, avoid nested card boilerplate, and preserve project design tokens.
- **When refining UI:** Apply Impeccable polish, balanced visual volume, and tabular numbers.
- **When adding motion:** Apply Emil Kowalski physics: under 300ms, `:active` scale(0.97), never scale(0), no keyboard lag, and spring easing.
- **When finalizing UI:** Verify keyboard accessibility, ARIA labels on icon buttons, and color contrast.

## 2. Slash Command Support
- Maintain user slash command dispatch for `/impeccable`, `/taste-skill`, `/emil-design-eng`, `/animate`, and `/web-design-guidelines`.
