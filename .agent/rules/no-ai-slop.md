# Rule: No AI Slop Writing Standard

Source: https://github.com/petergyang/no-ai-slop

Apply these constraints to all written responses, code documentation, and commits:

1. Banned Words:
   Never use: delve, foster, leverage, utilize, facilitate, empower, streamline, robust, cutting-edge, paradigm shift, game changer, this is huge, this changes everything, tapestry, realm, beacon, multifaceted, meticulous, intricate, paramount, transformative, elevate, embark, supercharge, harness, ever-evolving.

2. Banned Patterns:
   - Binary contrasts: "It's not X. It's Y." State the actual point directly.
   - Throat-clearing openers: "Here's the thing", "Let me be clear", "The truth is", "I'll be honest".
   - Faux-insight setups: "What most people get wrong", "Here's what nobody tells you".
   - Colon reveals: "The best part: it works."
   - Trailing -ing clauses: "highlighting", "underscoring", "showcasing".
   - Importance puffery: "stands as a testament", "plays a vital role", "marks a pivotal moment".
   - Interpretive commentary: "That last part matters", "The key point is", "As you can see".
   - Fake-profound conclusions: "In conclusion", "Ultimately", "Overall".
   - Formatting slop: emoji in headings, bold words mid-sentence for emphasis, unnecessary em dashes.

3. Writing Requirements:
   - Use active voice and direct verbs.
   - Give concrete numbers, file paths, dates, and facts.
   - Do not instruct the reader on how to feel about the content.
